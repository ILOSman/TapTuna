Требуется tshark

Для импорта и анализа .pcap / .pcapng TapTuna использует tshark из состава Wireshark. Без него нельзя импортировать трафик.

Как установить

ДистрибутивКоманда
Ubuntu / Debian / Mint sudo apt install tshark
Fedora / RHEL sudo dnf install wireshark-cli
Arch / Manjaro sudo pacman -S wireshark-cli
openSUSE sudo zypper install wireshark

При установке Ubuntu спросит про разрешение захвата — можно ответить No, для анализа файлов это не нужно.

После установки

Закройте и откройте TapTuna заново — при старте tshark подхватится автоматически. Либо нажмите кнопку ниже.
