Интерпретации

Как это работает? Разбор типов и стратегий

Интерпретация — декларативная модель, описывающая как разбить байтовый поток на сообщения (framing) и как извлечь из каждого сообщения поля (fields).

1. Framing

  • fixed — сообщения фиксированной длины (size).
  • length_prefix — N байт длины в начале (prefix_bytes, big_endian, length_includes_prefix).
  • delimiter — разделитель (delim hex, include_delim).
  • regex — регулярка (pattern, include_match).

2. Типы полей

u8 / i8 (1Б) · u16be/le, u24be/le, u32be/le, u64be/le · bytes · utf8/ascii · bcd.

3. Offset и Size

offset: auto (после предыдущего), N (абсолютный), from_end:N (от конца).
size: N, remaining, from_field:имя.

4. Constraints

Выражения над полями: temp >= -20 and temp <= 20. Не выполнено → при верификации сообщение получит статус violation.

5. Preview

Кнопка Preview позволяет сразу применить интерпретацию к выбранной сессии — посмотреть, что извлекается, до сохранения и запуска верификации.
